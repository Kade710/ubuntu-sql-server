# Project Notes

## Overview

This directory contains development notes for the Ubuntu SQL Server project.

These notes are used to document progress, decisions, testing, problems, fixes, and ideas that may not belong in the main project documentation.

## Contents

- `build_journal.md` - Running record of project development and major changes

## Purpose

Project notes help keep track of:

- Features that were added
- Problems that were discovered
- Solutions that worked
- Server configuration changes
- Testing results
- Design decisions
- Future ideas
- Lessons learned during development

## Documentation

Information in this directory may later be moved into permanent project documentation when a feature or process is completed.

The notes are meant to be practical and may change often while the project is under development.

## Security

Passwords, API keys, tokens, private keys, and other secrets should never be stored in project notes.

Sensitive server configuration should also be removed before notes are committed to Git.

## Status

This directory will continue to grow as development of the Ubuntu SQL Server project continues.
