# Compliance

This directory contains security and compliance documentation for the Ubuntu SQL Server project.

The goal is to document basic security practices used to protect the server, applications, database, and project data.

## Areas Covered

- Access control
- Password and secret protection
- Network security
- Database security
- Backup protection
- Software updates
- Logging and monitoring

## Documentation

- `security_baseline.md` - Defines the basic security standards used by the project.

## Status

Security practices will continue to be reviewed and improved as the project grows.
