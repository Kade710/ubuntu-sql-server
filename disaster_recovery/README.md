# Disaster Recovery

This directory contains disaster recovery documentation for the Ubuntu SQL Server project.

The goal is to provide a clear plan for recovering important services, data, and configurations after a system failure, data loss, or other major problem.

## Recovery Areas

Recovery planning may include:

- PostgreSQL database recovery
- Application recovery
- Configuration recovery
- Backup restoration
- Docker service recovery
- Minecraft server recovery
- Server rebuild procedures

## Documentation

- `recovery_plan.md` - Describes the basic recovery process for the project.

## Status

Disaster recovery procedures will continue to be updated as new services and backup systems are added.
