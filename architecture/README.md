# Architecture

This directory contains documentation about the design and structure of the Ubuntu SQL Server project.

The project uses several components that work together to collect, store, and display information about U-Server.

## Main Components

- PostgreSQL database
- Go monitoring agent
- Django web dashboard
- Python client
- Rust client
- Docker services
- Server automation tools

## Documentation

- `system_design.md` - Describes how the current system is organized.
- `future_design.md` - Documents possible future improvements and expansion.

## Status

The architecture continues to change as new monitoring, automation, and management features are added.
