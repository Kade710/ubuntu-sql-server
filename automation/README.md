# Automation

This directory contains automation tools and documentation used by the Ubuntu SQL Server project.

Automation is used to reduce manual server maintenance and make common management tasks easier to repeat.

## Current Areas

- Scheduled system tasks
- Server maintenance
- Database maintenance
- Backup automation
- Ansible configuration

## Structure

- `ansible/` - Ansible automation and configuration
- `cron_jobs.md` - Documentation for scheduled cron jobs

## Status

Automation is being expanded as new server management tasks are added to the project.
